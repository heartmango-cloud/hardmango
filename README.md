## วิธีเอาขึ้น GitHub Pages (สำหรับคนที่ไม่เคยใช้ GitHub)

ทำครั้งเดียว ไม่ต้องลงโปรแกรมอะไร ใช้เว็บอย่างเดียว

### 1 · สร้างที่เก็บไฟล์ (repository)

1. เข้า [github.com](https://github.com) แล้วล็อกอิน
2. กดปุ่ม **+** มุมขวาบน → **New repository**
3. **Repository name** ใส่ `hardmango` (หรือชื่ออะไรก็ได้ที่เป็นภาษาอังกฤษ ไม่มีเว้นวรรค)
4. เลือก **Public**
5. **อย่า** ติ๊ก "Add a README file"
6. กด **Create repository**

### 2 · อัปไฟล์

1. ในหน้าที่เพิ่งสร้าง กด **uploading an existing file**
2. ลากไฟล์ทั้ง 5 ตัวในโฟลเดอร์นี้ใส่ลงไป
   ```
   index.html      ← ตัวโปรแกรม
   sw.js           ← ทำให้เปิดออฟไลน์ได้
   manifest.json   ← ทำให้ติดตั้งเป็นแอปบนมือถือได้
   .nojekyll       ← บอก GitHub ว่าอย่าไปแปลงไฟล์
   README.md       ← ไฟล์นี้
   ```
   > ถ้าลาก `.nojekyll` ไม่ได้เพราะขึ้นต้นด้วยจุด ให้กด **choose your files** แล้วเลือกจากหน้าต่างไฟล์แทน
   > (บน Mac กด `Cmd + Shift + .` เพื่อให้เห็นไฟล์ที่ขึ้นต้นด้วยจุด)
3. เลื่อนลงล่างสุด กด **Commit changes**

### 3 · เปิด GitHub Pages

1. กดแท็บ **Settings** ด้านบนของ repository
2. เมนูซ้ายมือ เลือก **Pages**
3. หัวข้อ **Source** เลือก **Deploy from a branch**
4. **Branch** เลือก `main` และโฟลเดอร์ `/ (root)` แล้วกด **Save**
5. รอ 1–3 นาที แล้วรีเฟรชหน้านี้ จะเห็นลิงก์ขึ้นมา

เว็บของคุณจะอยู่ที่

```
https://ชื่อผู้ใช้ของคุณ.github.io/hardmango/
```

### 4 · ติดตั้งลงมือถือหรือ iPad (ไม่บังคับ)

- **iPhone / iPad** — เปิดลิงก์ใน Safari → กดปุ่มแชร์ → **เพิ่มไปยังหน้าจอโฮม**
- **Android** — เปิดใน Chrome → เมนูสามจุด → **ติดตั้งแอป**

ติดตั้งแล้วเปิดได้แม้ไม่มีเน็ต และไม่มีแถบเบราว์เซอร์มากินพื้นที่จอ

## เวลาจะอัปเวอร์ชันใหม่

1. เอาไฟล์ `index.html` ตัวใหม่ไปวางแทนของเดิม (กดที่ชื่อไฟล์ในหน้า repository → ไอคอนดินสอ → ลบของเก่าวางของใหม่ หรือ upload ทับ)
2. **สำคัญ:** แก้บรรทัดแรกของ `sw.js` ให้เลขเปลี่ยน
   ```js
   const CACHE = 'hardmango-v6.3';   // เปลี่ยนเลขทุกครั้งที่อัป
   ```
   ถ้าไม่เปลี่ยน เบราว์เซอร์จะยังใช้ของเก่าที่เก็บไว้

## ข้อมูลของคุณอยู่ไหน

เก็บใน **localStorage ของเบราว์เซอร์บนเครื่องคุณเอง** ไม่ได้ส่งไปไหนทั้งนั้น
เว็บนี้ไม่มีเซิร์ฟเวอร์ ไม่มีระบบสมาชิก ไม่มีการเก็บข้อมูลผู้ใช้

**ผลที่ตามมาที่ต้องรู้:**

- ข้อมูลใน**คอมกับในมือถือไม่ซิงก์กัน** ถือเป็นคนละชุด
- ถ้าล้างข้อมูลเบราว์เซอร์ ข้อมูลจะหาย
- **กด ⬇ Export เก็บไฟล์สำรองไว้เป็นระยะ** และใช้ ⬆ Import ย้ายข้ามเครื่อง
